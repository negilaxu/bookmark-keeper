# Bookmark Keeper

Bookmark Keeper is a simple browser app for saving and managing links in one place.

## Features

- Add bookmarks with a name and URL
- Open saved bookmarks in a new tab
- Delete bookmarks when they are no longer needed
- Persist bookmarks in the browser's `localStorage`

## Getting Started

No build step or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Select **Add Bookmark**, enter a website name and URL, then select **Save**.

## Project Structure

- `index.html` - Application markup and bookmark form
- `script.js` - Bookmark management, validation, and local storage
- `style.css` - Application styling and responsive layout
- `favicon.png` - Browser tab icon

Bookmarks are stored locally in the browser, so they are specific to the browser and device where they were added.
